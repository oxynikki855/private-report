# 一年，换一种工作方式

56 秒，1920 × 1080，30 fps。基于年度工作总结的个人成长短片。

打开 `index.html` 可播放、拖动进度、开关音乐和下载成片。最终 MP4 在 `out/growth-film.mp4`。

## 叙事与取舍

| 时间 | 内容 | 原文依据 |
| --- | --- | --- |
| 0–6s | 一年，换一种工作方式 | 报告封面、个人工作环境 |
| 6–13s | 从功能到问题结构 | 年度轨迹、供应链专题 |
| 13–21s | 小痛点长成工作环境 | COMM、Memoria、Obsidian、个人工作模式 |
| 21–29s | 从个人提效到组织提效 | 人才发展数据看板、可信数据管道 |
| 29–37s | 让别人用得起来 | Sailoom、复杂能力与任务入口 |
| 37–49s | 三个尚未解决的矛盾 | 反思章节的三个原句及其问题 |
| 49–56s | 继续走进真实现场 | 下一阶段销售运营 AI 落地、内部 FDE 讨论稿 |

舍弃项目编号清单、SKU、算法细节、工具横评和未经当前验证的成果指标。下一阶段仅作为探索方向，没有呈现为已经完成的成果。

四张原有手绘图经过去纸底处理，保留原图笔触和内容。各画面由绝对时间 `seek(t)` 驱动，可任意顺序取帧。采用局部揭示、微推镜、线条生长与短叠化，反思段降低视觉及音乐密度。

## 配乐

`music.py` 生成原创配乐：120 BPM，Cmaj7 / Am7 / Fmaj7 / Gsus2，拨弦与钟琴质感的合成音、轻柔和声、少量沙锤与低鼓。反思段减少音符和节拍，结尾自然收束。无第三方采样或商业歌曲。`out/music.wav` 为独立配乐，可替换。

## 重新生成

需要 Python 3、NumPy、Pillow、Python Playwright 及其 Chromium，以及 ffmpeg。当前机器已经具备。

```bash
cd /home/oxynikki/projects/工作汇报/growth-film
python3 prepare.py
python3 music.py
python3 render.py --preview
python3 render.py
```

文本与场景时间在 `index.html` 的 `shots` 中修改。`render.py --fps 60` 可渲染 60 fps 版本。

验证输出包括九个代表画面、联系表和手机预览；渲染时检查非空像素、同场景画面变化、浏览器错误和移动端横向溢出。成片使用 H.264 / yuv420p、AAC 和 faststart。
